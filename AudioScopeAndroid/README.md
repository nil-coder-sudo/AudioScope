# AudioScope（Android 版）

專業音訊分析 App：即時頻譜、即時瀑布圖、整首頻譜圖（找隱藏圖像）、電平、EBU R128 響度、真峰值、相位、向量示波器，以及完整的檔案資訊。

純 Kotlin、沒有任何第三方套件，Android 8.0（API 26）以上可用。

## 用 GitHub 自動編譯出 APK（不用裝 Android Studio）

1. 到 GitHub 建立一個新的 repository（公開或私人都可以）。
2. 把這個資料夾裡的**所有檔案**上傳上去。要包含隱藏資料夾 `.github`，網頁上傳時可以直接把整個資料夾拖進去。
3. 上傳後點上方的 **Actions** 分頁，會看到「Build APK」正在跑，大約 3–6 分鐘。
4. 跑完（綠色勾勾）點進去，在頁面最下方 **Artifacts** 下載 `AudioScope-apk`。
5. 解壓縮得到 `AudioScope.apk`，傳到手機安裝。第一次安裝時，手機會要求允許「安裝未知來源的應用程式」。

之後每次修改程式並推上 GitHub，都會自動重新編譯。也可以在 Actions 頁面按「Run workflow」手動觸發。

## 功能

**即時分頁**
- 波形總覽：點或拖曳後放開即可跳轉
- 即時頻譜：平滑曲線、峰值保持（橘色虛線）、自動標出峰值頻率與音名；手指按住可讀取頻率、dB 與音分
- 即時瀑布圖：按住可讀取頻率與時間
- 電平表：RMS（實心）、Peak（半透明）、峰值保持（白線，削波時變紅）
- 向量示波器（自動增益）與相位相關性
- 讀數：峰值頻率、音名、瞬時 M／短期 S／整合 I 響度、真峰值

**頻譜圖分頁**
- 整首歌的頻譜圖，可切換線性或對數刻度
- 兩指縮放（水平、垂直可各自縮放）、單指拖曳、點一下跳到該時間、點兩下還原
- 「自動對比」與上下限滑桿

**資訊分頁**
- 檔案、電平、響度（I／LRA／M／S／真峰值／PLR／各平台比較）、動態、立體聲、頻譜特徵、調性、BPM、品質檢測（有損轉檔、補零位元深度、削波、DC）、標籤
- 可複製或分享成文字報告

**其他**
- 麥克風即時分析：支援的裝置會優先使用「未處理」音源（沒有自動增益和降噪），分析比較準
- 可以從檔案管理員選「用 AudioScope 開啟」，或從其他 App 分享音檔進來
- ⚙ 設定：FFT 大小、窗函數、頻率刻度、色彩、聲道（混合／L／R／Mid／Side）、顯示範圍、平滑、瀑布長度、峰值保持

## 支援格式

WAV 由 App 自己解析，支援 8／16／24／32 bit 整數與 32／64 bit 浮點，會保留真實位元深度。MP3、AAC／M4A、FLAC、Ogg Vorbis、Opus 等格式用手機內建的解碼器處理。

## 用 Android Studio 編譯（選用）

用 Android Studio 開啟這個資料夾，等 Gradle 同步完成，再按 ▶ Run，或選 Build → Build APK(s)。
